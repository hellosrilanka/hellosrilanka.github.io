# Hello Sri Lanka — Multi-page website

Ready-to-edit static website built with **HTML, CSS and JavaScript**. No build tools, server-side code or paid libraries required.

## Start

1. Unzip the package.
2. Double-click `index.html` to preview in your browser.
3. For a public website, upload the **entire contents** of the `hello-srilanka` folder to your web host (Netlify, GitHub Pages, cPanel / public_html or another static host). Keep the folder structure intact.

## Pages

- `index.html` — homepage
- `tours.html` — six suggested trip options and clickable filters
- `destinations.html` — island inspiration and category filters
- `fleet.html` — sedan and two KDH vans
- `pricing.html` — both rate methods and working estimate calculator
- `about.html` — brand story
- `contact.html` — inquiry form, WhatsApp booking handoff and social links

## Important customizations before launch

- `assets/hello-srilanka-logo.jpg` comes from your supplied logo image, cropped to reduce the white margin.
- Add **your own actual vehicle and destination photography** if available. The website currently uses remote illustrative Unsplash photography, which requires an internet connection, may not accurately depict the named place or actual fleet and can be replaced by local files. The vehicle icons are illustrations rather than vehicle photos.
- Pricing uses owner-supplied starting rates: USD 80/day OR Rs.150/km + Rs.5,000/day for driver meals/accommodation. The calculator and package day-rate subtotals are *indicative*, not confirmed total quotes. Specify tax, fuel, parking, tolls, mileage limits, lodging and all inclusions/exclusions explicitly in your agreement with each guest.
- Confirm service terms, cancellation policy, vehicle capacity, availability and booking/payment terms before launch. No ratings/review claims have been fabricated; Tripadvisor links to your supplied listing.
- WhatsApp contact is +94 71 717 8383. The form does **not** store data on a server; it creates a pre-filled WhatsApp message and visitors must send it there.
- Social links are from the supplied Instagram, Facebook and Tripadvisor URLs. Check that they open publicly.
- Google Fonts and photo backgrounds load from third-party services. The HTML/CSS/JS, logo, page navigation, filters and calculator are included locally.

## Edit

`css/style.css` controls design; `js/main.js` controls navigation, calculator, filter and inquiry behavior. Edit each HTML page for page-specific copy or imagery. Shared header/footer markup is copied into each HTML page so you can deploy it without a generator.

## Suggested enhancements before a larger launch

Add actual fleet photos, testimonials only with guest permission, a verified Google Business listing, transparent terms, privacy notice, a real domain, analytics with consent as required, optimized locally hosted imagery and a server-backed form only if needed.
